Multi-Cloud & K8s Defense

Cloud & Kubernetes Security Posture Management

Audit AWS, Azure, GCP, and Kubernetes clusters against official CIS Benchmarks and Infrastructure-as-Code (Terraform / K8s manifests).

Amazon Web Services (AWS)

Audits S3 bucket public access (read/write ACLs and policies), missing KMS/SSE encryption, IAM *:* wildcard administrator roles, and open Security Group ports (22, 3389, 3306, 5432).

CIS AWS Foundations v3.0 S3 Hardening IAM Least-Privilege

Kubernetes (KSPM / PSS)

Enforces Pod Security Standards (PSS): detects container privilege escalation (privileged: true), root user execution, sensitive hostPath mounts (/var/run/docker.sock), and hostile system:anonymous RBAC bindings.

CIS Kubernetes v1.8 Pod Security Standards RBAC Audit

Microsoft Azure

Inspects unencrypted Storage Account blob services, missing HTTPS transport enforcement, public blob container access, and Network Security Group exposures across Azure infrastructure.

CIS Azure Benchmark Blob Encryption NSG Control

Google Cloud Platform (GCP)

Scans Google Cloud Storage buckets granting public read/write permissions to allUsers or allAuthenticatedUsers, uniform bucket-level access misconfigurations, and compute policies.

CIS GCP Benchmark GCS Access Controls IAM Defense
